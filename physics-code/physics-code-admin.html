الرسائل المرسلة

هدية دنانير للاعبين النشطين

الخطوة 1: اختار عدد الأيام واضغط «معاينة» حتى تعرف كم لاعب راح يستلم. الخطوة 2: اكتب المبلغ وأرسل. الحد الأعلى 1000 دينار لكل لاعب. اللاعب المحظور ما يستلم.

أزرار التحكم باللعبة

كل تغيير يوصل للاعبين بأول مرة يفتحون اللعبة بعده، بدون تحديث من المتجر. وكل تغيير ينكتب بسجل العمليات.
