هدية دنانير للاعبين النشطين

الخطوة 1: اختر عدد الأيام واضغط «معاينة» لتعرف عدد اللاعبين الذين سيستلمون الهدية. الخطوة 2: اكتب المبلغ وأرسل. الحد الأعلى 1000 دينار لكل لاعب، ولا يستلمها اللاعب المحظور.
